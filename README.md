## Installation

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/ketsiakanyere52-blip/flutter_cv.git
   ```

2. Entrer dans le projet :

   ```bash
   cd flutter_cv
   ```

3. Installer les dépendances :

   ```bash
   flutter pub get
   ```

4. Lancer l'application :

   ```bash
   flutter run
   ```
